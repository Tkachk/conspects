Тип System.String, хранятся в куче 
`string имя_строки = значение`

Экранирование позволяет изолировать строчные символы по типу /t что бы не заюзать табуляцию в выводе строки
`Console.WriteLine("//swaga lyutaya//"); == Console.WriteLine(@"/swaga lyutaya/");`

Индексатор - позволяет по индексу получить элемент строки. Работает только в режиме чтения.

метод CopyTo - копирует заданное колво символов в массив типа char.

Compare сравнивает 2 строки возвращает int, где 0 это одинаковые строки, 1 если разные строки.

substring это часть строки то есть слово в предложении например.

метод Substring возвращает подстроку 

метод Split разделяет строку и создает массив,  str.Split(" ", 3) - разделить по пробелу начиная с индекса 3.
