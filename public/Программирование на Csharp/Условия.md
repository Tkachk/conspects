Условие - логическое выражение, которое используетя для реализации алгоритма ветвления. Условие это логическая величина и выражается в виде лексической единицы. 

```
a > b // простое условие
a > b && b > c // составное условие
```

Тип данных - контейнеры с информацией

Структура данных - организованное хранение и использование или преображение типов данных

Алгоритм - решение какой либо задачи определенным способом с явным и известным сценарием. I/O

## IF - условный оператор управления потоком. Обязательным условием является то, что значением выражения в if обязательно должно быть значение типа bool.

```
if (условное выражение)
{
	действие
}
```

private static bool IsCheckPassLogin(string login, string password, string role)
{
	List<string> logins = new List<string>()
	{
		"vasya", "123";
	};
	
	if(login == logins[0] && password == logins[1] && role == "user")
	{
		Console.WriteLine("Авторизовался как пользователь.");

	}
}

## **Оператор switch**

Switch - условный оператор принимающий одно значение переменной.

```

private static bool IsCoinRank(int rank)
{
	switch(rank)
	{
		case 1:
			Console.WriteLine("Это рубль!");
			break;
		case 2:
			Console.WriteLine("Это 2 рубля!");
			break;
		case 5:
			Console.WriteLine("Это 5 рублей!");
			break;
		case 10:
			Console.WriteLine("Это 10 рубле!");
			break;
		default:
			Console.WriteLine("Нет монет!");
			break;
	}
}

```

## Тернарный оператор ?

```
	Условие ? действие при true : действие при false
```

пример использования

```
string GetWeatherDisplay(double tempInCelsius) => tempInCelsius < 20.0 ? "Cold." : "Perfect!";

Console.WriteLine(GetWeatherDisplay(15));  // output: Cold.
Console.WriteLine(GetWeatherDisplay(27));  // output: Perfect!
```
