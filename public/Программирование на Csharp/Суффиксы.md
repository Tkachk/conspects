## Специальные символы 

| Char | Значение                                                                               | Юникод |
| ---- | -------------------------------------------------------------------------------------- | ------ |
| \’   | Одиночная кавычка                                                                      | 0x0027 |
| \»   | Двойная кавычка                                                                        | 0x0022 |
| \\\\ | Обратный слэш                                                                          | 0x005C |
| \0   | Null (символ конца строки)                                                             | 0x0000 |
| \a   | Alert                                                                                  | 0x0007 |
| \b   | Backspace                                                                              | 0x0008 |
| \f   | Перевод страницы                                                                       | 0x000C |
| \n   | Новая строка                                                                           | 0x000A |
| \r   | Возврат каретки                                                                        | 0x000D |
| \t   | Горизонтальный таб                                                                     | 0x0009 |
| \v   | Вертикальный таб                                                                       | 0x000B |
| `@   | Ультимативный \\, все выводит так как оно написано не затрагивая все что написано выше |        |
