Операторы - это лексемы, которые на уровня языка являются псевдонимами некоторых операций.

| Категория             | Операторы                     | Описание                                           |
| --------------------- | ----------------------------- | -------------------------------------------------- |
| Арифметические        | `+` `-` `*` `/` `%` `++` `--` | Математические вычисления                          |
| Сравнения             | `==` `!=` `>` `<` `>=` `<=`   | Сравнивают значения, возвращают `bool`             |
| Логические            | `&` `\|` `^` `!` `&&` `\|\|`  | Операции над булевыми значениями                   |
| Побитовые / сдвиговые | `~` `<<` `>>` `>>>`           | Операции над битами целочисленных типов            |
| Присваивания          | `=` `+=` `-=` `*=` `/=` `%=`  | Сохранение значений в переменных                   |
| Условный (тернарный)  | `?:`                          | Краткая проверка условия                           |
| Объединение null      | `??`                          | Возврат значения, если другое `null`               |
| Типа                  | `is` `as`                     | Проверка и приведение типов                        |
| Доступа               | `.` `()` `[]` `=>`            | Доступ к членам, вызов методов, индексация, лямбды |
