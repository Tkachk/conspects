Существует 2 типа цикла: итерационный и рекурсивный

при рекурсии функция внутри себя же вызывает функцию

при итерации происходит действие поочередно со всем значениями цикла

Пример итерации:
```
int i = 100;
int sum = 0;

while(i < 0)
{
	sum += i;
	i--;
}
```

Пример рекурсии:

```
public static int f1(int arg)
{
	if (arg == 0) // проверка на 0
	{
		return 0;
	}
	
	return f1(arg - 1); // возвращает в себя же значение -1
}
```

Итерация - одноразовое выполнение тела цикла

Итератор - переменная определяющая количество итераций

Условие выхода - условие определяющее выход из циклической конструкции

Циклы с предусловием - условие проверяется до выполнения тела цикла

Циклы с постусловием - условие проверяется после выполнения тела цикла

Циклы с счетчиком
Циклы без счетчика

Условные циклы
Безусловные или бесконечные циклы

Циклы коллекции - цикл прохода walkthrough cycles создаются для выполнения определенной процедуры над всеми элементами массива, множества и тд. например foreach

```
for (инициализация переменных; условное выражение; выражение)
{
	тело цикла
}
```


List = масштабируемое
массив  = определенное место

break позволяет прерывать циклы (выходить из них)
continue переносит на следующую итерацию цикла

```
static void Main(string[] args)
{
	int i = 0;
	while(True)
	{
		if (++i % 6 == 0)
		{
			Console.WriteLine(i);
		}
		if (i == 100)
		{
			break; // при i == 100 стопит бесконечный цикл
		}
	}
}
```

```
static void Main(string[] args)
{
	for (i = 1; i < 20; i++) // цикл от 1 до 20 с шагом 1
	{
		if (i % 2 != 0) // проверка четности
		{
			continue; // пропуск нечетного итератора
		}
		Console.WriteLine(i); // вывод четного
	}
}
```
